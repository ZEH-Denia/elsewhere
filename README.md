## 本地运行

工程使用 React、TypeScript、Vite 与 Tailwind CSS，包管理器为 npm。`package.json` 遵循 Vite 的运行要求：Node.js 20 系列需 20.19.0 或更高版本，其他版本需 22.12.0 或更高版本；本轮实际使用 Node.js v24.16.0、npm 11.13.0。

```bash
npm ci
npm run dev
```

开发服务默认地址为 `http://127.0.0.1:5173/`。另开终端可执行：

```bash
npm run typecheck
npm run test:story
npm run build
npm run preview
```

生产构建输出到 `dist/`（不提交），预览服务默认地址为 `http://127.0.0.1:4173/`。`npm run test:story` 同时检查第一通的两次选择/四结局，以及扩展职业线的四职业、16 组合、16 封信、身份差异、兜底文案、信件解锁和重置。

当前版本包含第一通完整剧情与第二通扩展：第一通的两次选择和四种结局保持原样；结局后可继续选择三种“现在的你”，进入四职业线路总机。每条职业线保留两次选择和四种结局，读完任一条线路的信件后会解锁音乐自我的最终回电与最后一封信；其他线路仍可返回总机重听。

夜色双室插画保持不透明度 1，首页、前言、来电、对白与选择统一使用贴在画面底部的纸面面板与选项按钮，中央不再铺白雾；仅第一通结局保留原有居中局部纸衬底。说话人标签跨在对话框上沿，进度与紧凑的“继续”位于页脚；选项按钮在悬停或键盘聚焦时以独立图层预览对应场景。换场保留旧场景做 220ms 交叉淡化，不会出现白场。桌面与手机主行动位置继续复用现有规则。

职业通话分别使用代码生成的专属场景，四条职业线各 4 张；可用 `node scripts/generate-backgrounds.mjs` 重新生成全部 40 张本地 SVG。信件页使用现有暖米纸面阅读区。扩展流程支持点击画面继续、键盘按钮、减少动态效果和返回首页。双世界时间线、分享、存档或后端仍未实现；不需要 API Key、账号或远程素材，不保存剧情进度；刷新页面会回到首页。

MVP 不要求用户提供 API Key，也不要求配置后端。团队已持续授权每轮改动完成并检查后自动提交、推送：指挥文档同步 main，Qoder 开发与返修同步任务分支。代码合并 main、网站部署与赛事投稿按协作协议另行批准。
