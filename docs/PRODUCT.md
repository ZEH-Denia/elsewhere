# 产品定义

**Elsewhere：未接来电** 是一个中文浏览器互动故事。玩家接到来自平行世界自己的电话，在选择中看到另一种人生的收获与代价。故事为虚构。

## 已实现体验

| 阶段 | 玩家体验 |
| --- | --- |
| 第一通 | 从前言进入来电，接听、读台词并作出两次选择。现实中的工程专业和平行世界的音乐专业各有所得，四种组合到达四种不同结局 |
| 第二通 | 首通结束后可选择三种身份，进入医生、教师、设计师和创业者线路。两次选择影响各职业的结局与来信 |
| 最终回电 | 读完任一职业来信后，可从总机进入音乐自我的最终回电与来信，也可返回总机继续体验其他线路 |

## 交付重点

- 体验面向桌面浏览器。关键操作可点击、可用键盘完成，焦点可见，尊重减少动态效果偏好。
- 中文台词和信件易读，按钮层级清晰。雨夜插画、暖米纸面、砖红操作和雾蓝信号共同构成界面视觉。
- 分支结果可区分，退出、重听与返回路径按各阶段的规则工作。构建和浏览器验收分别记录。
- 项目范围内的剧情和素材均在本地，暂缓手机版开发与窄屏验收。账号、AI、数据采集、分享、存档及双世界时间线属于未实现范围。
