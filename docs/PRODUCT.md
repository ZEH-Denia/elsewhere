## 目标与定位

- 产品名：**Elsewhere：未接来电**。
- 一句话：接到来自平行世界自己的电话，通过互动剧情探索另一种人生。
- 场景：约三分钟、无需注册的浏览器互动叙事，适合手机，也能在桌面演示。
- 赛事方向：LifeHack 生活娱乐；以清晰叙事、选择反馈和完整体验提高竞争力，不承诺获奖。

## MVP 体验

神秘首页 → 来电/接听 → 沉浸式对话 → 两个关键选择 → 双世界时间线 → 平行世界来信 → 重新体验。

首个故事固定为“现实世界选择工程类专业，平行世界选择音乐专业”。双方各有收获与代价，不塑造某条人生绝对成功或失败；故事为虚构，不预测真实未来。

两个关键选择各提供两项可理解的选项，四种组合必须通向四种可区分的结局。区别要体现在后续对话、时间线事件和结尾来信中，不能只更换结局标题。选择的影响以叙事反馈呈现，不建设复杂数值模拟。

## MVP 完成条件

- 从首页到结尾和重新开始均可操作，无空按钮、死路、失效选择。
- 两次选择的四条路径全部可到达，重开后状态清空。
- 手机与桌面无横向溢出；内容可读，核心操作可见且可用键盘完成。
- 深蓝/紫色/青色的电影感视觉，轻量动效，支持减少动态效果偏好。
- 构建、类型检查和实际浏览器体验有证据；可公开访问的版本在授权发布后另行验收。
