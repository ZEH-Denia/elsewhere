## 开工时的 Git 操作

Codex 为首次交接准备 `task-001` 分支，起点与本轮交接文档的 main 提交一致。执行方先实查，不能假定自己电脑上已有本地分支。

1. 同一台电脑：直接使用现有项目目录，不重新克隆或新建第二层项目。
2. 其他电脑：从 [GitHub 仓库](https://github.com/ZEH-Denia/elsewhere) 克隆后，在 Qoder 打开仓库根目录。读取公开仓库不要求写权限；推送需使用有权限的账号。
3. 先检查 `git status --short --branch`；存在未交接改动时保留并报告，不强制切换、不清理文件。
4. 工作区干净时执行 `git fetch origin`，切到 `task-001`，再 `git pull --ff-only origin task-001`。若没有本地分支，使用 `git switch --track origin/task-001`；若已有分支则使用 `git switch task-001`，不重置已有分支。
5. 查看 `git log -1 --oneline` 并确认本文件存在；仅在任务分支内开发。远程分支缺失、拉取冲突或权限受阻时报告，不自行改 main 或重建仓库。
