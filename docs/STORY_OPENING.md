# TASK-002 首通来电执行用稿

> 历史执行用稿，记录 TASK-002 的首通来电脚本。当前应用使用 `main` 中的 `src/story/opening.ts`。 [项目现状](PROJECT_STATUS.md)

日期：2026-11-17。用途：供 Qoder 实现 TASK-002 的固定本地剧情。此稿属于产品内容，不是业务代码；完整四结局尚未在本轮实现。后续团队可统一校订，Qoder 本轮不自行扩写世界观或生成额外剧情。

## 场景与约束

用户扮演选择工程类专业的大学生，来电方是选择音乐专业的平行世界自己。两者的生活各有得失，故事不评价真实用户的专业选择或预测其未来。不询问姓名、专业或其他个人信息。

首次关键选择以“如何回应遗憾”为主题。后续 TASK-003 继续使用该选择记录，增加第二次选择与四种结局；本轮只交付第一段通话闭环。

## 前言与来电

- 前言保留：“如果当年选择了音乐，你现在会在哪里？”
- 必须保留声明：“这是一段虚构的平行人生，不代表对真实未来的预测。”
- 前言操作：“进入来电”“返回首页”。
- 来电身份：“另一个你”；来源说明：“来自平行世界的自己”。
- 来电操作：“接听”“返回首页”。这是剧情模拟，不调用系统电话、不播放声音、不请求麦克风或通知权限，不显示真实网络连接承诺。

## 接听后的主线对话

一次展示一条当前对话，也可以保留清楚的已读记录；不要自动滚走或定时跳过。角色名必须可见。

| 稳定内容标识 | 角色 | 台词 |
| --- | --- | --- |
| opening-01 | 另一个你 | 喂？先别挂。如果我说，我也是你呢？ |
| opening-02 | 你 | 这是什么恶作剧？ |
| opening-03 | 另一个你 | 那年填志愿，我把工程改成了音乐。你是不是没有改？ |
| opening-04 | 你 | ……没有。我留在了那条更稳妥的路上。 |
| opening-05 | 另一个你 | 我刚结束一次排练。能演自己写的歌很开心，可下个月的演出费还没着落。 |
| opening-06 | 你 | 我在准备实习。生活有了安排，但那把吉他已经很久没碰过。 |
| opening-07 | 另一个你 | 所以我想问，你现在最想对另一个自己说什么？ |

opening-07 后进入选择，普通“继续”操作不允许绕过该选择。

## 第一次选择与反馈

选择标识建议固定为 `first-response`。两个选项不设正确答案、分数或排名。

| 选项标识 | 用户看到的选项 | 反馈 1 另一个你 | 反馈 2 你 |
| --- | --- | --- | --- |
| regret | 我有点遗憾，没继续学音乐。 | 我也会想，如果当年选了工程，会不会少一些不安。也许我们都看见了另一边的光。 | 也许可以先把那把吉他找出来，不用马上推翻整个生活。 |
| cherish-present | 我也有想珍惜的，当下的生活。 | 那就先别急着否定它。我舍不得舞台，也羡慕你身边那些安稳的日常。 | 我想先认真过好今天，也给喜欢的事留一个位置。 |

两条反馈各按顺序展示，再显示共同收束台词：

> 另一个你：电话快断了。至少这一次，我们听见了彼此。

此句仅为故事情节，不用真实网络倒计时、永久加载或设备权限表现“断线”。

## 本段结束

标题：“第一通来电，暂时结束。”

- regret 路径摘要：“你说出了遗憾，也给一次小小的尝试留了位置。”
- cherish-present 路径摘要：“你珍惜当下，也没有关上另一种可能。”

提供两个有效操作：

1. “重听这通来电”：清空对话位置、第一次选择及反馈，从来电页重新开始，需再次主动接听。
2. “返回首页”：清空本轮剧情状态，回到初始首页；再次开始可重新选择另一项。

本页不称“最终结局”，不展示尚未实现的时间线、第二次选择、分享或生成按钮。产品 README 如实说明本轮仅完成首段通话，不把它当完整 MVP。

## 中途离开

首页、前言、来电的返回不需要确认。已接听进入对话/选择/反馈后，提供“结束通话”；有当前进度时使用轻量确认：“结束本次通话并返回首页？”取消保持原节点与选择，确认后清空并返回首页。对话末段已结束的两个操作不再重复确认。

确认可以用语义正确、键盘可用的原生或轻量实现，不为此引入 UI 套件。刷新始终回首页，无需存档。
