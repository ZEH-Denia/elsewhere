## 在自己的电脑运行

1. 安装 Git、npm 及项目支持的 Node.js 版本。Node.js 20.x 从 20.19.0 起，22 系列从 22.12.0 起，也支持更高版本。
2. 首次获取项目时运行下列命令。已有副本按 [GitHub 协作入门](GITHUB_COLLABORATION.md) 更新当前分支。
3. 打开终端显示的本地地址，开发服务默认使用 `http://127.0.0.1:5173/`。

```sh
git clone https://github.com/ZEH-Denia/elsewhere.git
cd elsewhere
git switch task-003
npm ci
npm run dev
```

需要使用生产构建时运行 `npm run build` 后再运行 `npm run preview`。工程检查为 `npm run typecheck`、`npm run test:story` 和 `npm run build`。
