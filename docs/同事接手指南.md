## 3. 第一次连接并打开

准备 Git、支持当前项目要求的 Node.js 和 npm，以及 Qoder IDE。`package.json` 要求 Node **20.19.0 及以上的 20.x，或 22.12.0 及以上**；项目曾在 Node 24.16.0/npm 11.13.0 和 Node 26.13.0/npm 11.20.0 下检查。Windows 可用 PowerShell 或 Git Bash，macOS/Linux 用终端。

在希望保存项目的目录中运行：

```sh
git clone https://github.com/ZEH-Denia/elsewhere.git
cd elsewhere
git fetch origin
git switch --track origin/task-003
git status --short --branch
git log -1 --oneline
node -v
npm -v
```

这是新克隆时的命令。已经有本项目目录时，不要在里面再次克隆：先 `git status --short --branch` 检查本地改动；干净后运行 `git fetch origin`，已有本地任务分支用 `git switch task-003`，再 `git pull --ff-only origin task-003`；没有本地任务分支再用上面的 `git switch --track origin/task-003`。若切换、拉取报错或存在未交接改动，保留现场并找负责人/Codex 处理，不要强推、重置、清理或覆盖。

在 Qoder IDE 中打开刚才的 `elsewhere` **项目根目录**，确认终端仍处于 `task-003`。首次安装和运行：

```sh
npm ci
npm run dev
```

打开终端实际显示的本机地址，默认一般为 `http://127.0.0.1:5173/`；端口占用时以实际输出为准。这是本机开发预览，不是公开网站。在另一个项目终端进行工程检查：

```sh
npm run typecheck
npm run test:story
npm run build
npm run preview
```

`npm run preview` 是生产构建的本机预览，先执行 build，以终端输出的地址为准。2026-11-18 本机在 `task-003` 运行 typecheck、剧情测试 13/13 和 build 均通过；这些结果不代表待修 R1 已通过，也不代替你设备上的安装、浏览器和验收检查。没有配置 lint 脚本。
