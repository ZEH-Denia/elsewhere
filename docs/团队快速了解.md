# Elsewhere：未接来电｜团队快速了解

三分钟了解我们要做什么，以及你可以参与什么。更新于 2026-11-16。

## 这是什么项目？

**一个可以在手机或电脑浏览器里体验的互动故事：你接到来自平行世界自己的电话，听见另一种人生，并通过选择改变故事走向。**

我们准备将它作为「2026 Qoder 高校创造力大赛」LifeHack 生活娱乐赛道的作品。首版目标是做出约三分钟、无需注册、从开场到结尾都能走通的体验。

可以这样向别人介绍：

> 如果当年你选择了另一条路，现在会过着怎样的生活？在《Elsewhere：未接来电》中，另一个世界的你打来一通电话。你们交换彼此的经历，做出选择，最后收到一封来自那个人生的信。

## 用户会怎么玩？

打开神秘首页 → 接听来电 → 与另一个自己对话 → 做两次关键选择 → 查看两个世界的人生时间线 → 收到来信 → 重新体验其他结局。

首个故事围绕一个大学生熟悉的问题：**专业与人生选择**。

- 现实世界的你选择了工程类专业。
- 平行世界的你选择了音乐专业。
- 两条人生都有收获，也有代价；故事希望让人理解选择、遗憾与当下。
- 两次选择各有两个选项，形成四种可区分的结局；选择会影响后续对话、时间线和结尾来信。

具体台词、选项和结局内容还需要团队共同打磨。剧情为虚构，不代表对真实未来的预测。

## 我们希望它吸引人的地方

- **开场有悬念**：一通来自另一个自己的电话，让人想接下去。
- **故事有共鸣**：围绕专业、热爱和生活中的取舍，让大学生能代入。
- **选择有回应**：玩家能看见自己的选择如何影响故事，愿意再走另一条路线。
- **画面有氛围**：深蓝、紫色与青色的夜间来电感，搭配克制的动效和清楚的文字。

这些是体验目标，是否成立要靠组员实际试玩来判断。

## 首版要做到哪一步？

先做好**一个故事、两个关键选择、四种结局和完整重玩流程**，同时兼顾手机与桌面。

首版使用预先编写的本地剧情，AI 工具帮助开发。暂不接入实时 AI 生成、真实电话、账号、后端或付费功能；更多人生主题和分享图留待后续评估。

## 我们怎么合作？

| 参与方 | 负责什么 |
| --- | --- |
| 团队成员 | 决定产品方向、打磨剧情和视觉、实际试玩、准备展示材料、批准下一任务与发布 |
| Codex | 技术指挥：拆解任务、写验收标准、检查实现、提出返修；不直接编写业务代码 |
| Qoder IDE | 开发执行：按任务写代码、运行验证、记录结果、按审核意见修复 |
| Git / GitHub | 记录版本与协作备份；已连接私有仓库，组员加入后可在不同设备获取项目 |

每轮按这个顺序推进：**Codex 写任务 → Qoder 开发并交报告 → Codex 审核或要求返修 → 团队批准后进入下一轮。**

同一时间由一方修改项目文件。组员可以同时讨论剧情、整理素材和记录体验问题；涉及代码或任务范围的改动，先汇总到当前任务，避免多方同时改同一份文件。

## 组员现在可以做什么？

以下是可认领的工作方向，具体负责人由团队商定：

- **剧情与文案**：写出两个世界各自的收获与代价，讨论两次选择为什么难选、四种结局有什么实质区别。
- **视觉与氛围**：整理少量色彩、排版或来电界面的参考，并说明喜欢哪里、希望用在哪里；记录素材来源。
- **试玩与反馈**：等首页交付后，用自己的手机和电脑体验，记录看不懂、点不动、文字被挡或让人出戏的地方。
- **展示与参赛材料**：整理一句话介绍、核心亮点与演示思路，记录 AI 工具如何参与开发；正式发布前由团队核对赛事规则。

提问题时用这个格式，方便直接转成修复任务：

> 我用的设备/浏览器：……；操作步骤：……；实际发生：……；希望的结果：……；附截图（如有）。

团队接下来最值得先讨论的是：**玩家结束这通电话后，我们希望他带走什么感受？** 这个答案会帮助我们统一剧情、视觉和结尾。
