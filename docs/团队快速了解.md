# Elsewhere：未接来电｜团队快速了解

你接到一通来自平行世界自己的电话。那个人当年选了音乐，你走上了工程这条路。通话中的选择会改变后面的对话和结局。

## 可以体验什么

1. **第一通来电**。接听后读台词并作出两次选择，走向四种结局之一。
2. **第二通来电**。选择你此刻的身份，接入医生、教师、设计师或创业者的线路。每条职业有四种结局和来信。
3. **最终回电**。读完任一封职业来信后，总机会提示音乐自我回电。你可以接听，也可以继续体验其他职业。
