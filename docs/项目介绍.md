# Elsewhere：未接来电 项目介绍

《Elsewhere：未接来电》是一部中文浏览器互动小说。故事从雨夜的一通电话开始。你扮演一个当年选择工程的人，来电者是平行世界里选择了音乐的自己。你可以接听这通电话，读他们的对话，选择怎样回应，然后看到这次谈话留下的结果。

## 这个项目有什么作用

作品把「如果当年选了另一条路，我现在会怎样」变成一次可以参与的故事。平行世界的自己会告诉你那条路带来了什么，也会说起其中很少被人看见的代价。你们可以谈各自珍惜的事，也可以说说那些仍然放不下的事。

故事把一个很大的问题缩小成几件具体的事。一次选择关乎你怎么看过去，另一次关乎你现在能做什么。比如，当你说自己还遗憾没继续学音乐，你可以决定给喜欢的事留一点时间，也可以先找一个信任的人聊一聊。两种行动都会得到不同的回应。玩家可以重听同一条线路，换一种回答，看看同样的处境还能怎样面对。

工程带来的稳定、音乐带来的满足，都和各自的困难写在一起。后面的职业线路延续这个主题。救人的确定感与值夜班的疲惫、创作的自由与交稿的压力，会出现在同一通电话里。玩家可以重听不同线路，比较自己会为怎样的生活心动，也在意哪一种代价。

## 一次体验会经过什么

**前言 → 第一通来电 → 选择身份 → 线路总机 → 职业来电与来信 → 最终回电**

1. **接听第一通来电。** 先听工程与音乐两边的近况，再做两次选择。第一次决定你怎样看待当年的选择，第二次决定你想尝试哪种行动。两次选择的组合通向四种结局。
2. **选择此刻的身份。** 第一通结束后，可以继续扮演「继续留在工程路上」「已经开始工作」或「刚离开工程」的自己。身份影响后续职业线的内心回应与来信开头。
3. **从总机接入一条职业线路。** 总机列出医生、教师、设计师和创业者四种人生。每条线都从一个具体处境切入，提供两次选择、四种结局和四封对应来信。
4. **读完一封信。** 职业来信写于通话一周后，讲述另一个你之后做了什么。读完任意一封并返回总机，即可解锁音乐自我的最终回电。你也可以继续接入其他线路。
5. **接听最终回电。** 音乐自我重新接起开头的话题，并根据第一通的结局用不同的开场回应你。这一通电话和最后一封信为故事收尾。

## 选择怎样改变故事

第一通的两次选择分别处理感受和行动。四种组合在当下的对白、首通结局和后续回电开场留下不同的内容。

| 你怎样看当年 | 你想做什么 | 第一通结局 |
| --- | --- | --- |
| 承认错过音乐的遗憾 | 给喜欢的事留一点时间 | 把旋律找回来 |
| 承认错过音乐的遗憾 | 找一个信任的人聊一聊 | 让遗憾被听见 |
| 珍惜现在拥有的生活 | 给喜欢的事留一点时间 | 给今天留一首歌 |
| 珍惜现在拥有的生活 | 找一个信任的人聊一聊 | 和身边的人分享 |

职业线把这种结构放进不同的生活。每条线的两次选择决定该线路的结局和来信正文，身份选择让内心回应和信件开头贴近你扮演的人。

| 线路 | 你听见的处境 | 这条线邀请你想什么 |
| --- | --- | --- |
| 医生 | 凌晨的急诊走廊，有位病人和医生同岁 | 持续照顾别人时，怎样照顾自己 |
| 教师 | 白天的教室里，一位学生说自己想放弃画画 | 鼓励别人保留热爱时，怎样重新看待自己的热爱 |
| 设计师 | 凌晨交稿前，客户觉得第一版更合适 | 喜欢的事成了工作以后，怎样给自己的创作留出空间 |
| 创业者 | 周一的办公室里，服务器刚续费，工资还没着落 | 自己做决定的自由，怎样与责任和孤独一起承担 |

## 新版桌面界面如何呈现故事

任务分支里的新版桌面界面用来电卡、信号状态和逐句台词呈现电话。玩家可以点击「继续」，或在阅读对白时点击画面推进。到达分支时，页面先给出问题，再列出答案。鼠标悬停或键盘聚焦某个选项时，画面的光线或场景会提示可能的走向，实际选择由按下选项确认。

插画也在交代剧情。工程房的暖色台灯和音乐房的冷蓝雨窗区分第一通的两种生活。四条职业线用急诊走廊的贩卖机、教室最后一排的窗、设计稿和创业办公室的雨窗建立各自的处境。职业来信把电话里的决定带到一周后的生活中，让玩家看到一次谈话留下的后续。

## 运行与验收状态

目前以桌面浏览器为主要体验环境。玩家打开页面即可开始，接听使用网页内的文字模拟。剧情与插画由静态网页加载，进度保存在当前页面内，刷新会开启一轮新体验。桌面版支持可见的键盘焦点和减少动态效果偏好。

工程使用 React、TypeScript、Vite 和 Tailwind CSS。剧情根据本地编写的台词与分支数据推进，四条职业线共用一套选择、结局、来信和回电规则。新增剧情内容可以沿用这些规则编写。 [本地运行说明](../README.md#本地运行) · [技术方案](ARCHITECTURE.md)
