## 2 本轮目标与边界

在已有工程上完成“深夜私人来电”的视觉打磨，并交付以下真实可玩的首段流程：

**首页 → 前言 → 来电 → 接听 → 七条主线对话 → 第一次选择 → 对应反馈 → 本段结束 → 重听/返回。**

本轮只实现一次关键选择、两种明确反馈。完整第二次选择、四结局、双时间线、结尾来信仍在后续任务，不得用本段结束页冒充完整 MVP 或最终结局。

## 3 首页与通用视觉

按 `docs/VISUAL_DIRECTION.md` 执行，下列为本轮必须落地部分；与任务有冲突时以本任务为准。

- 中文“未接来电”成为主要叙事标题，英文 Elsewhere 保留为品牌；标题、引导、来电身份和主操作有清楚层级。
- 保留深蓝底、冷青与浅紫的空间感，增强“另一个你”的来电主视觉，减少重复边框与大面积空卡片。两个世界也有文字标识，不只靠颜色。
- 手机重新构图：390×844 首页在页面顶部时，标题、来电身份“另一个你”和“开始体验”按钮均能识别，主按钮完整位于首屏；不要求装饰与页脚全部放入首屏。
- 320px、矮屏和放大文字时允许自然滚动，不通过缩小正文、锁定高度或遮挡内容达成首屏目标。
- 首页、前言、来电、对话/选择与本段结束页共用一致的色彩、字形、间距、图标和按钮语言；可合理拆成小组件。
- 正文以 16–18px 为起点；正常正文在实际背景/透明层上以对比 4.5:1 为内部验收目标。辅助说明保持可读。
- 动效以轻量 opacity/transform 为主；无定时强制推进、声音自动播放或等待动画结束才能操作。支持减少动态效果，保留可见焦点和至少 44×44px 触控目标。
- 继续使用本地 CSS/SVG 和系统字体，不引入远程素材、字体、3D 引擎或大型动效库。

## 4 首通来电功能

### 4.1 固定内容与状态

- 使用 `docs/STORY_OPENING.md` 的执行用稿、稳定标识、两个选项及各自反馈。仅可调整换行和排版，不擅自改写剧情或增加角色；确有疑问在报告说明。
- 首页保留唯一主操作“开始体验”；前言保留问题与指定虚构声明，增加真实“进入来电”，继续提供“返回首页”。
- 来电页展示“另一个你 / 来自平行世界的自己”，提供“接听”“返回首页”；接听后开始对话，不需麦克风、通知、账号或真实通话能力。
- 对话中明确标注“你”和“另一个你”；用户点击“继续”推进当前句，七条主线后必须进入第一次选择，不允许越过选择直接到结束。
- 选择后记录稳定的选项标识，展示对应两条反馈，再展示共同收束台词；两项的后续内容与结束摘要有实质区别。
- 结束页标题为“第一通来电，暂时结束。”，提供可用的“重听这通来电”和“返回首页”，不出现未实现的分享、时间线或后续按钮。

### 4.2 重置与中途离开

- 重听从来电页重新开始，清空对话位置、第一次选择、反馈和结束摘要；需要再次主动接听。
- 返回首页清空本轮状态；再次开始可选择另一项，不能残留上次反馈。刷新回首页，不做云存档或本地持久化。
- 已接听的中途提供“结束通话”与轻量确认；取消继续当前节点，确认清空并返回首页。前言/来电直接返回及已结束后的返回无需重复确认。
- 快速连点不能绕过选择、同时接受两项或造成重复结算；动画和焦点处理不能吞操作、造成卡死或保留隐藏按钮可聚焦。

### 4.3 可访问性

- 新页面/状态让键盘和辅助技术能感知变化；对话更新可适当使用当前句播报，避免反复播报整段历史。
- 按钮使用语义化控件；Tab、Enter、Space 可以完成整段流程。确认层若使用模态，保持焦点范围、关闭后回到合理位置。
- 原有返回首页后的焦点恢复继续有效；新交互不破坏减少动态效果偏好。

## 5 工程实现要求

- 沿用 React + TypeScript + Vite + Tailwind 和 npm，不重新初始化、不更换技术栈、不混用锁文件。
- 将剧情内容、节点/选项标识与转移信息整理为有类型的本地结构化数据，与页面展示分开；本轮没有通用剧情引擎或全局状态库需求。
- 为主线、两条反馈和收束保留可追踪节点；相同输入产生相同反馈。缺失节点/非法状态应能明确恢复，不能白屏或随机选择。
