## 2. 本轮目标

让团队能在本地打开一个有 Elsewhere 氛围的首页，并验证“开始体验”确实切换到有内容、可返回的来电前言。交付一个小而完整的入口，供 Codex 检查工程、设计与交互基础。

## 3. 功能与视觉要求

### 首页

- 展示完整名称 **Elsewhere：未接来电**，可将英文与中文分层排版。
- 简短引导文案必须传达“来自平行世界的自己”；可使用“如果当年，你做了另一个选择。”，避免大量设定说明。
- 唯一主操作为 **开始体验**，使用语义化按钮；页面初次打开即能识别主要行动。
- 深蓝为底，紫色/青色局部光晕，营造夜间未知来电的氛围；留白清楚、正文易读。
- 使用轻量 CSS 或本地矢量装饰，不依赖远程图片、字体、音频或素材下载；不申请通知、麦克风权限，不自动播放声音。

### 点击后的真实行为

- 点击“开始体验”，在同一单页切换到**来电前言**，显示“如果当年选择了音乐，你现在会在哪里？”或语义一致的中文内容。
- 明确写出“这是一段虚构的平行人生，不代表对真实未来的预测。”
- 提供 **返回首页**，点击恢复初始首页，再次开始仍可使用。
- 切换后让键盘/辅助技术能感知新内容（例如聚焦新标题，或使用适当播报）；焦点可见，切回首页后操作可继续。
- 本轮不提供尚未实现的“接听”“分享”“生成”等按钮，也不显示永远不会结束的连接或加载动画。

### 适配与动效

- 至少检查 390×844、1440×900；同时在 320px 宽度检查无横向溢出、按钮不被裁切。矮屏允许自然滚动，不锁死页面高度。
- Tab 可到达按钮，Enter/Space 可触发；交互元素可见焦点，触控目标不小于 44×44 CSS 像素。
- 保持正文与按钮对比清楚；装饰不遮挡内容。尊重 `prefers-reduced-motion`，无持续高强度闪烁。
